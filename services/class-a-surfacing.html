Class A Surfacing

Flawless, curvature-continuous surfaces for visible parts.

What we do

Class A surfaces are the visible skins of a product — car body panels, aircraft fairings, consumer-product housings. We build G2/G3-continuous surfaces with clean patch layouts and verify them with zebra and curvature analysis, so reflections flow without a ripple.

01

G2 / G3 continuity

Curvature-continuous transitions between every patch for perfect reflections.

02

Analysis-verified

Zebra stripes, highlight lines and curvature combs checked on every surface.

03

From scan or sketch

Start from a clay-model scan, a reference surface or concept sketches.

FAQ

Class A Surfacing FAQ.

Can you create Class A surfaces from a 3D scan?

Yes. We scan the physical model or part, then build new Class A surfaces that follow the scan within an agreed tolerance, with clean G2/G3 continuity.

What's the difference between Class A surfacing and reverse engineering?

Reverse engineering focuses on accurate, manufacturable geometry. Class A surfacing adds strict control of surface continuity and reflection quality for visible surfaces.

Which file formats do you deliver?

Neutral formats such as STEP and IGES, which open in CATIA, NX, Alias and other platforms.
